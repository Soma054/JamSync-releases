# JamSync

Apple Music をみんなで同時に聴くアプリ（Mac / Windows）の配布用ページです。

## ダウンロード

右の **Releases** から最新版を選び、使っている PC に合わせてダウンロードしてください。

- **Mac**: `JamSync-Mac.zip` を開き、中の `JamSync.app` をアプリケーションフォルダへ。はじめて開くときは、右クリック →「開く」を選んでください。
- **Windows**: `JamSync-Windows.zip` を展開し、中の `JamSync.exe` を起動します。iTunes for Windows が必要です。

一度入れれば、新しい版が出たときにアプリの中でお知らせが出て、ボタン1つでアップデートできます。
